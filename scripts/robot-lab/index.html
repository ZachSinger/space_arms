A robot is a frame (its body and speed), one logic board per board slot, and a power cell. A prefab board does one fixed job you can't change; a custom board holds commands you write. The frame and boards together need some power; the cell's capacity must cover it or the robot won't switch on. The cell's charge runs down as the robot works and fills back up on a charging station. The robot checks its boards from slot 1 down and does the first thing that fits: a prefab board that has work to do, or a command whose "if" part is true and whose job can be done right now. If nothing fits, it waits. Press Play on the right and watch which command each robot picks (the green row). Changes apply while it runs.
