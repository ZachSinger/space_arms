Each robot follows its program from the top down and does the first rule that fits: the "if" part is true and the job can be done right now. If no rule fits, it waits. Each rule uses up one chip slot. On the right is a pretend store: press Play and watch which rule each robot picks (the green row). You can change programs while it runs. Robots charge at charging stations in the backroom; a robot whose battery runs flat shuts down for the rest of the shift.
